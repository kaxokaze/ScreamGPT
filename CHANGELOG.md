# Changelog

## 1.6.0

- Refined the popup to an ultra-minimal interface with system light/dark theme support.
- Bundled eight WAV sound effects and added custom MP3/WAV support.
- Added sound selection, preview, volume, and Test sound controls.
- Added accessibility settings for larger text, high contrast, reduced motion, and keyboard navigation.
- Added a ChatGPT-page-only refresh reminder when the content script is missing or outdated; the user initiates the reload.
- Kept settings and custom audio on-device; no desktop notification feature.
- Packaged the extension as a ready-to-load folder, so end users do not need Node.js, npm, or a build step.
